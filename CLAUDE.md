# Instructions pour Claude

## Mode vocal

Quand l'outil MCP `voice_speak` est disponible :
- Utilise-le pour répondre vocalement quand l'utilisateur le demande explicitement ("parle", "dis-moi", "réponds à voix haute")
- Utilise-le pour les confirmations courtes après une action ("C'est fait", "Fichier créé")
- Ne l'utilise PAS pour les longues explications ou le code (garde ça en texte)

## Exemples

- "parle" → utiliser voice_speak
- "dis-moi ce que tu as trouvé" → utiliser voice_speak
- "explique-moi le code" → répondre en texte (trop long pour la voix)
